1. AUTENTICACIÓN
============================================================

REGISTRO DE USUARIO

Método:
POST

Endpoint:
http://localhost:8082/api/auth/register

Ruta:
POST /api/auth/register

Body:

{
  "username": "project_user",
  "password": "ClaveSegura123"
}

Respuesta correcta:
201 Created

{
  "message": "Usuario registrado correctamente."
}

Usuario duplicado:
409 Conflict

{
  "message": "El usuario ya se encuentra registrado."
}


INICIO DE SESIÓN

Método:
POST

Endpoint:
http://localhost:8082/api/auth/login

Ruta:
POST /api/auth/login

Body:

{
  "username": "project_user",
  "password": "ClaveSegura123"
}

{
  "message": "Autenticación satisfactoria."
}

Autenticación incorrecta:

{
  "message": "Error en la autenticación."
}

2. ALOJAMIENTOS
============================================================

CREAR ALOJAMIENTO

POST http://localhost:8082/api/accommodations

Ejemplo:

{
  "name": "Suite Campestre",
  "description": "Alojamiento confortable para parejas y familias pequeñas.",
  "capacity": 4,
  "pricePerNight": 290000,
  "available": true
}

Respuesta correcta:
201 Created


CONSULTAR TODOS LOS ALOJAMIENTOS

GET http://localhost:8082/api/accommodations

Respuesta:
200 OK


CONSULTAR ALOJAMIENTO POR ID

GET http://localhost:8082/api/accommodations/{id}

Ejemplo:

GET http://localhost:8082/api/accommodations/2

Respuesta:
200 OK

Si no existe:
404 Not Found


CONSULTAR ALOJAMIENTOS DISPONIBLES

GET http://localhost:8082/api/accommodations/available

Respuesta:
200 OK


ACTUALIZAR ALOJAMIENTO

PUT http://localhost:8082/api/accommodations/{id}

Ejemplo:

PUT http://localhost:8082/api/accommodations/2

Respuesta:
200 OK

Si no existe:
404 Not Found


ELIMINAR ALOJAMIENTO

DELETE http://localhost:8082/api/accommodations/{id}

Respuesta:
204 No Content

Si no existe:
404 Not Found
